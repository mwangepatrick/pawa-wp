# Typography — KISWA Kenya

## Recommended Font Stack

All fonts are available free via Google Fonts: https://fonts.google.com

---

### Heading Font — Poppins
**Google Fonts:** https://fonts.google.com/specimen/Poppins

| Weight | Use |
|---|---|
| 700 (Bold) | H1, H2, hero titles |
| 600 (SemiBold) | H3, H4, card titles |
| 500 (Medium) | H5, H6, sub-headings |

- Modern, geometric, and highly legible on screen
- Widely used by NGOs and social impact organisations
- Confident and approachable — fits an advocacy organisation

---

### Body Font — Inter
**Google Fonts:** https://fonts.google.com/specimen/Inter

| Weight | Use |
|---|---|
| 400 (Regular) | Body paragraphs, descriptions |
| 500 (Medium) | Button labels, captions, labels |

- Designed specifically for screen readability
- Clean and neutral — lets content speak
- Works excellently on mobile (important for Kenyan audiences)

---

### Accent / Pull Quote Font — Lora
**Google Fonts:** https://fonts.google.com/specimen/Lora

| Weight | Use |
|---|---|
| 400 Italic | Pull quotes, testimonials, impact statements |
| 700 Bold | Featured statistics ("10,000+ women served") |

- Serif with warmth and character
- Adds emotional weight to impact quotes and stories
- Contrasts beautifully with Poppins and Inter

---

## Font Size Scale (Recommended)

| Element | Size | Weight | Font |
|---|---|---|---|
| H1 (Hero) | 48–56px | 700 | Poppins |
| H2 (Section) | 36–40px | 700 | Poppins |
| H3 (Card) | 24–28px | 600 | Poppins |
| H4 | 20px | 600 | Poppins |
| Body | 16px | 400 | Inter |
| Small / Caption | 14px | 400 | Inter |
| Button | 14–16px | 500 | Inter |
| Pull Quote | 20–24px | 400 Italic | Lora |

---

## Google Fonts Import (for WordPress/CSS)

```css
@import url('https://fonts.googleapis.com/css2?family=Poppins:wght@500;600;700&family=Inter:wght@400;500&family=Lora:ital,wght@0,700;1,400&display=swap');
```

---

## Notes
- The current theme (Pagelayer/Elementor) likely already has a default font — these should be set via the theme's Global Typography settings
- Poppins + Inter is one of the most common and well-tested NGO website font pairings
- All three fonts are free, load fast, and have excellent Kenyan/East African audience support
