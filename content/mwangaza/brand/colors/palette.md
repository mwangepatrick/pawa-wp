# Mwangaza — Brand Colour Palette

Extracted from the official logo: `Mwangaza-Intergrated-Logo.png` (WP ID: 6012)

## Primary Palette

| Role | Name | Hex | Source in logo |
|---|---|---|---|
| Primary / Sunburst | Mwangaza Gold | `#F5A320` | Sunburst rays behind the hands — dominant visual element |
| Headline / Bold | Unity Red | `#E8342A` | "MWANGAZA" text fill |
| Accent / Fresh | Lime Green | `#72D64A` | Outline stroke on "MWANGAZA" text |
| Secondary | Deep Purple | `#8544AD` | "INTEGRATED PROJECT" text |
| Background | White | `#FFFFFF` | Logo background |
| Body Text | Dark Charcoal | `#1A1A1A` | For all body copy on light backgrounds |

## Derived / Support Colours

| Role | Name | Hex | Usage |
|---|---|---|---|
| Gold tint | Warm Cream | `#FEF3E2` | Section backgrounds, card backgrounds |
| Gold dark | Amber | `#C47D0E` | Hover/pressed state for gold buttons |
| Red dark | Crimson | `#B5231A` | Hover state for red elements |
| Green tint | Mint Wash | `#EDF9E6` | Light section backgrounds |
| Purple tint | Lavender Wash | `#F3EBF9` | FAQ, secondary content sections |
| Muted | Stone | `#5A5A5A` | Captions, meta text, timestamps |

## Website Usage Rules

| Element | Colour |
|---|---|
| Primary CTA buttons (Donate, Get Involved) | `#F5A320` bg + `#FFFFFF` text |
| Primary CTA hover | `#C47D0E` bg + `#FFFFFF` text |
| Secondary buttons / ghost | `#E8342A` border + `#E8342A` text |
| Page headings (H1, H2) | `#E8342A` |
| Section headings (H3, H4) | `#1A1A1A` or `#8544AD` |
| Links | `#E8342A`, hover `#B5231A` |
| Header background | `#FFFFFF` with bottom border `#F5A320` |
| Footer background | `#1A1A1A` with `#FFFFFF` text |
| Active nav item | `#F5A320` underline or text |
| Highlight / badge | `#72D64A` bg + `#1A1A1A` text |

## Accessibility

| Combination | Contrast Ratio | Result |
|---|---|---|
| `#FFFFFF` on `#F5A320` | ~2.8:1 | ⚠️ Use bold/large text only |
| `#1A1A1A` on `#F5A320` | ~7.2:1 | ✅ AAA |
| `#FFFFFF` on `#E8342A` | ~4.5:1 | ✅ AA |
| `#FFFFFF` on `#8544AD` | ~4.9:1 | ✅ AA |
| `#FFFFFF` on `#1A1A1A` | ~18:1 | ✅ AAA |
| `#E8342A` on `#FFFFFF` | ~4.5:1 | ✅ AA |

**Note:** For CTA buttons using Gold (`#F5A320`), always use dark text (`#1A1A1A`), not white.
